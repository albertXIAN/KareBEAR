# Palette reference

Sampled from the centre of each solid stripe in `palette.png` (900×600, five equal columns). Values are sRGB.

| Swatch | Hex | Role |
| --- | --- | --- |
| Lilac | `#F5CCFF` | `brandAccent`, quiet-room wall, rug, bear halo |
| Mint | `#C9FDD9` | Soft panels, checkup and garden walls, success fills |
| Periwinkle | `#ABCAFF` | `brandPrimary`, buttons. Light version is the main wall. |
| Coral | `#FFB3B1` | `brandSecondary`, warnings, cuff |
| Butter | `#FFE4AE` | Small accents only, such as the tired-bear fill |

These swatches are all light. White text fails contrast on every one, so labels use darkened versions of the same hues:

| Derived | Hex | How |
| --- | --- | --- |
| Ink | `#2B3340` | Periwinkle × 0.25. Body text and text on buttons. |
| Soft ink | `#3D4960` | Darkened periwinkle for descriptions. |

| Mint ink | `#405145` | Mint × 0.32. Success labels. |
| Coral ink | `#614443` | Coral × 0.38. Warning and error labels. |

Large backgrounds use the same hues mixed 58% toward white. The main wall is periwinkle `#DCE9FF`. Mint panels are `#E8FEEF`, lilac `#FBEAFF`, coral `#FFDFDE`. Buttons and small accents keep the original swatches. Card outlines use periwinkle `#ABCAFF`. Cards themselves stay white.
